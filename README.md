# Magdalena

Referenzprojekt für den reversiblen Camping-Ausbau eines VW T3 Syncro (BJ 1991, ehem. KDO-F).

## Dokumente

| Datei | Inhalt |
| --- | --- |
| [docs/t3-syncro-camping-referenz.md](docs/t3-syncro-camping-referenz.md) | Führende Referenz: Campingbox, Innenraum, Dachgepäckträger, Anhänger mit Dachzelt |

## Phasen

1. **Campingbox + Innenraum** (Konzept pausiert)
2. Vorhandener Pongratz 230er Heavy mit Dachzelt für bis zu 3 Kinder; 2 MTB an der Deichsel, Kinderräder im Hänger
3. Busdach nur Gepäck (Westfalia-Träger, mindestens 4 Bögen)

Leitprinzip: maximaler Erhalt des Sammlerzustands – keine Karosseriebohrungen, Fixierung per Zurrgurte, mindestens 5 Sitzplätze.
