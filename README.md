# Magdalena

Referenzprojekt für den reversiblen Camping-Ausbau eines VW T3 Syncro (BJ 1991, ehem. KDO-F).

## Dokumente

| Datei | Inhalt |
| --- | --- |
| [docs/t3-syncro-camping-referenz.md](docs/t3-syncro-camping-referenz.md) | Führende Referenz: Campingbox, Innenraum, Dachzelt auf dem Bus, Anhänger für Gepäck |

## Phasen

1. **Campingbox + Innenraum** (Konzept pausiert)
2. Dachzelt Thule Approach M auf dem Bus für bis zu 3 Kinder
3. Pongratz 230er Heavy für Gepäck: 2 MTB an der Deichsel, Kinderräder und Sperriges im Hänger

Leitprinzip: maximaler Erhalt des Sammlerzustands – keine Karosseriebohrungen, Fixierung per Zurrgurte, mindestens 5 Sitzplätze.
