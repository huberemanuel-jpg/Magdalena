# Magdalena

Referenzprojekt für den reversiblen Camping-Ausbau eines VW T3 Syncro (BJ 1991, ehem. KDO-F).

## Dokumente

| Datei | Inhalt |
| --- | --- |

## Phasen

1. **Campingbox + Innenraum** (aktuell)
2. Anhänger (Räder + sperriges Gepäck)
3. Dachzelt (bis 3 Kinder)

Leitprinzip: maximaler Erhalt des Sammlerzustands – keine Karosseriebohrungen, Fixierung per Zurrgurte, mindestens 5 Sitzplätze.
